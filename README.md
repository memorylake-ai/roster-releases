# Roster desktop app · 数字员工桌面客户端

Installers and the auto-update feed for **Roster**, MemoryLake's AI digital employees for Feishu, WeCom and DingTalk.
This repository only hosts releases; the product page is <https://memorylake.ai/roster> (中国站 <https://memorylake.cn/roster>).

本仓库只用来发布 Roster 数字员工桌面客户端的安装包与自动更新清单。产品介绍见 <https://memorylake.cn/roster>。
